#  One Piece - Página Web  

Este proyecto es una página web dedicada al anime y manga **One Piece**, desarrollado como **trabajo práctico para la materia Programación IV**.  

##  Descripción  
La página presenta información organizada sobre el universo de One Piece, incluyendo:  
- Sinopsis de la serie.  
- Personajes principales.  
- Arcos argumentales.  
- Grupos y organizaciones (marina, piratas, ejército revolucionario, etc.).  

El objetivo fue aplicar conceptos de **HTML, CSS y JavaScript**, además de una estructura de carpetas ordenada para imágenes, estilos y contenido, siguiendo buenas prácticas de desarrollo web.  

##  Tecnologías utilizadas  
- **HTML5** → estructura de la página.  
- **CSS** → diseño y estilos, con hojas separadas para galería e index.  
- **JavaScript** → interacción básica y dinamismo.  


##  Objetivos del trabajo práctico  
1. Crear un sitio web estático con al menos **3 secciones enlazadas**.  
2. Aplicar **estilos propios** con CSS externo.  
3. Mantener **coherencia visual** (colores, tipografía, alineación de imágenes).  
4. Practicar **organización de carpetas** para reutilización de recursos.  
5. Documentar el proyecto en un archivo `README.md`.
